# 스피드라인 추월컷 커버리지

## 사용자 작업

기준 포켓몬을 선택하고 자기 스피드 노력0~32를 조정한다.
현재 누구를 추월하는지, 다음 컷에 필요한 최소 노력을 확인한다.
이전 준속~최속 범위 막대는 이 작업을 지원하지 못해 기본 화면에서 교체했다.

## 계산 범위

- 자기 스피드는 기존 `calculateSpeed`로 계산한다. 자기 성격은 상승/무보정, 노력은0~32. 자기 스카프 미적용·랭크0·특성 미발동이다.
- 상대의 일반 준속/일반 최속/스카프 준속/스카프 최속을 별개 조건으로 센다. 상대 노력32, 무보정/+10% 성격, 랭크0·특성 미발동이다.
- 엄격히 빠를 때만 추월이다. 동속은 별도 집계한다.
- 최소 추월 노력은 기존 `calculateSpeedInvestment`를 통해0~32를 전방 열거한다. 직전 노력에서 미추월인지 함께 회귀 검사한다.
- 스카프를 쓸 수 없는 메가 폼은 스카프 조건과 분모에서 제외한다.
- 분모는 폼·도구·성격으로 구분된 조건 수다. 사용률·승률·실제 상대 빌드의 확률이 아니다.
- 같은 추월 집합이 유지되는 연속 노력 구간은 한 행으로 묶는다.

## 화면

- 기준 검색·자기 성격·동기화된 노력 슬라이더/숫자 입력.
- 현재/최대 실수치, 네 분류 커버리지, 동속, 다음 최소컷과 추가 노력.
- 노력 구간 표는 새 대상 수만 보여준다. 구간 선택 시 노력·URL·대상 목록이 함께 바뀐다.
- 선택 구간의 새 추월 대상은 별도 검색 목록에서 전체 제공한다. 검색은 전체 커버리지 분모·분자를 바꾸지 않는다.
- 노력0에서는 ‘이미 추월’ 대상으로 명시한다. 대상을 숨긴 Top-N 집계가 아니다.
- 320/390px 표는 카드형 두 열로 표시한다. 긴 대상 목록은 내부 스크롤하며 가로 스크롤을 요구하지 않는다.
- 잘못된 숫자 초안은 결과를 숨기고 수정하면 복구한다.

## 호환

`view=ranges` 토큰을 보존하면서 기본 내용만 커버리지로 교체했다.
자기 노력·성격은 `refEp`·`refNature`로 복원한다.
개별 조건 계산은 별도 모드로 유지한다.
새 개별 조건 계산의 구애스카프 기본값은 미적용이다.
기존 링크의 `items=both/scarf`는 명시한 값 그대로 복원한다.
