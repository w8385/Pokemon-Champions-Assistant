상태: **요구·설계 계약, 미구현**. 근거는 `whole-app-ui-refresh/requirements.md`(기준 커밋 `f61858f`, 소스 정적 조사), `component-inventory.md`(공용 제어 실사), `browser-audit/report.md`(2026-10-20 공개 앱 읽기 전용 조사)이다. 원본은 `/home/w8385/.hermes/artifacts/pokemon-champions/` 아래에 있다. 브라우저 조사와 소스 기준의 배포 리비전 동일성은 확인되지 않았으므로 서로 다른 종류의 증거로 취급한다.

## 범위와 공통 계약

표시 메뉴 8개는 홈 `#/`, 내 파티 `#/party`, 대면 `#/single?tab=party`(공개 앱 이동 뒤 `#/single?my=0&opp=0`), 계산기 `#/damage`, 스피드라인 `#/speed-line`, 샘플 라이브러리 `#/sample-builder?sampleTab=library`, 샘플 연구소 `#/sample-builder?sampleTab=builder`, 도감 `#/dex`이다. 8개 직접 링크와 각 화면의 첫 행동을 유지한다. `#/double`은 메뉴/홈에서 숨기되 기존 코드·저장 데이터·딥링크를 삭제하지 않는다. 구 single/sample-builder 탭 및 `/sample-library/:id`도 보존한다.

동일한 종·기술 검색은 시각적 복제가 아니라 **실제 입력을 소유하는** `SearchCombobox`/`PokemonSearchField`/`RegisteredMoveSlot`을 재사용한다. 표시 순위·화살표·Enter의 후보를 일치시키고 IME/229, Escape/Tab/blur, 초점 이동 및 툴팁을 보존한다. 파티·빌더·양측 비교에 이미 쓰이는 `PokemonBuildFields`, `PokemonStatGrid`, `EffortTuningModal`의 콜백·66점 한도·게이지·모달 포커스 복귀를 유지한다. 이미 공유된 `QuickDamagePanel`을 또 유사한 카드로 복제하지 않는다.

입력과 즉시 바뀌는 수치/결과를 가깝게 배치한다. 의미 있는 실수치, 유효 스피드, 피해, 조건, 미확인/미지원·오류 이유는 숨기지 않고 반복 설명만 줄인다. 같은 화면에서 편집과 계산이 가능해야 하며 결과를 보기 위해 저장을 요구하지 않는다. 기록 소유권은 파티/상대 등록, 대면의 슬롯·seed별 비교 초안과 명시적 원본 반영, 계산기의 독립 임시 저장, 빌더 초안/개인 저장본/파티 적용, 스피드라인 URL 조건, 읽기 전용 라이브러리·도감으로 구별한다. 저장 실패를 성공으로 표시하지 않는다. **엔진·스키마·데이터 소스·저장 의미 변경은 이 UI 계획의 범위 밖**이다.

공통 수락 기준은 헤더·홈 직접 링크/정확한 active 상태, 직접 URL·수정키 새 탭·같은 경로 재선택·Back/Forward·reload, 빈/부분/로딩/오류/무효 상태와 복구, KO/EN/JA의 의미 보존이다. 데스크톱 1280폭과 좁은 390폭에서 첫 행동·첫 결과의 위치, 카드/팝업/모달 실제 순서와 hit target, 문서 overflow, 대비·가독성을 측정한다. 모바일 viewport 포인터 결과를 **실기기 터치 합격**으로 대체하지 않는다.

## 메뉴별 목표

1. **홈:** 8개 직접 목적지 중 원하는 작업을 한 번에 열고, 소개보다 시작 행동을 앞세운다. 자체 저장 없음.
2. **내 파티:** 6개 등록 카드를 같은 화면에서 수정하고 그 **뒤**에 18타입×6슬롯 분석을 둔다. 분석은 선출 추정과 독립, 등록 기술/폼에 반응한다. 작업 파티 자동 보관·이름 붙인 프리셋·초기화/가져오기를 명확히 구분한다.
3. **대면:** 내 등록 슬롯과 상대 슬롯의 종/폼을 고정 소유자로 삼아 두 카드·공통 척도의 유효 스피드·양방향 4기술 피해를 한 작업 문맥에 놓는다. 상대 검색 선택만 실제 슬롯 등록과 다음 빈 슬롯 초점 이동을 일으킨다. 일시 가정은 원본에 쓰지 않고 원본 반영은 대상이 명확한 명시적 행동으로만 한다.
4. **계산기:** 동일 `QuickDamagePanel`에서 양쪽 종을 자유 검색하고 임시 공수 교체·조건 편집·즉시 결과를 제공한다. 파티/상대 등록과 독립된 임시 저장을 유지한다.
5. **스피드라인:** 기준 실제/유효 스피드, 항상 보이는 목록 검색, 스카프·특성 필터와 속도 차이를 가까이 둔다. URL 상태·잘못 복원된 대상 복구를 유지하고 설정을 접힌 `details`나 장문 설명 뒤에 숨기지 않는다.
6. **샘플 라이브러리:** 필터/검색→출처 있는 읽기 전용 상세→목록 복귀. 확정/미확인 필드를 구분하고 확인된 개별 샘플은 빌더 초안으로, 완전한 파티만 별도 저장 파티로 가져온다. 읽기만으로 등록 기록을 바꾸지 않는다.
7. **샘플 연구소:** 종/메타/노력/4기술 편집과 스피드·피해 결과의 거리를 줄이고 `내 샘플로 저장`, `빌더 초안으로 불러오기`, `파티에 적용`을 서로 다른 대상 행동으로 노출한다. 기존 인라인 즉시 노력 조정은 역할을 검토하기 전 삭제하지 않는다.
8. **도감:** 미선택 첫 진입에서 범주/통합 검색과 점진적 카드 목록, 독립 상세를 제공한다. 전체 후보 ID가 끝까지 나타나야 하고 검색/범주/선택/스크롤·직접 상세 URL을 복원한다. 빌더 열기·파티 적용은 명시적 대상 선택이며 도감 자체는 읽기 전용이다.
