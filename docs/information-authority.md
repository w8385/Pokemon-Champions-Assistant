# 정보별 기준과 기록 소유권

이 문서는 현재 고정 자료의 생산자와 실제 소비 경로를 설명합니다.
단일 기준(SOT)은 모든 정보를 한 파일에 모은다는 뜻이 아닙니다.
각 필드와 기록의 소유자를 하나로 정하고, 실제 조회 경로를 연결합니다.
현행 게임·레귤레이션과의 동등성은 별도 검증 대상입니다.

## 저장과 임시 상태는 별개 소유자

- `partyWorkspace.ts`: stable 파티 ID와 등록 슬롯·기술의 master입니다. 파티 목록 선택 후 편집은 해당 기록에 자동 저장됩니다.
- `comparisonDraftState.ts`: side·slot·seed에 묶인 sparse dirty build patch입니다. 쓰기와 읽기가 같은 순수 검증을 사용합니다. 거절된 쓰기는 기존 성공값과 반대 슬롯을 건드리지 않습니다.
- 대면의 명시적 master 반영: 임시 비교 편집과 구분합니다. 비교 초안 저장이 master 변경을 뜻하지 않습니다.
- 독립 Quick: 별도 저장 키의 두 카드·수동 조건을 소유합니다. 대면 편집이 독립 Quick를 덮어쓰지 않습니다.
- 날씨·필드·랭크·실수치 가정: 전투 시나리오입니다. 유효한 폼별 특성만 자동 효과에 전달하며 수동 override와 자동 소유를 구분합니다.
- 제작자 원본: 출처별 알려진 필드와 기록된 실수치의 폼 귀속을 보존합니다. 미기록 값·명시적 공란·기록된 0을 구분합니다.
- 기존 백업: 역사적 기록의 비파괴 진입 정책입니다. 새 편집의 엄격한 검증을 이유로 과거 파티의 미확인 값을 자동 삭제·확정하지 않습니다.

## 재현·검증 명령

```sh
node --test tests/*.test.mjs
npm run typecheck
node scripts/build-champions-move-meta.mjs --offline --check
npm run build
git diff --check
```

의도적으로 기술 메타를 재생성할 때는 다음을 실행합니다.
생성 전에 대상 변경과 입력 증거를 확인합니다.

```sh
node scripts/build-champions-move-meta.mjs --offline
```

`--check`는 산출물·리포트가 오래됐으면 실패하며 파일을 쓰지 않습니다.
생성기는 HTTP·소켓을 차단한 subprocess 테스트에서도 실행됩니다.
Pages workflow는 타입 검사·전체 테스트·오프라인 검사를 배포 빌드 전에 실행합니다.

주요 회귀 파일:

- `sharedLearnsets.test.mjs`, `moveMetadataAuthority.test.mjs`, `moveMetadataProducer.test.mjs`
- `abilityIdentityAuthority.test.mjs`, `itemIdentityAuthority.test.mjs`
- `speciesFieldAuthority.test.mjs`: 실제 App의 341폼·백업 수용·필드·1,705개 파생 속도
- `comparisonDraftState.test.mjs`: 쓰기/읽기 동치와 거절된 쓰기의 기존값 보존
- `liveQuickFields.test.mjs`: 실제 컴포넌트의 자동 조건·수동 없음·수치·리셋·독립 저장

## 검증 범위의 한계

고정 자료의 내부 일관성과 실제 앱 동작을 검증합니다.
외부 로스터 전체 네트워크 sync, 현행 게임·규정 동등성, 유료 OCR 실호출,
실제 휴대폰 터치와 전체 접근성 인증은 별도 검증하지 않은 범위입니다.
부분 폼·메뉴·언어 QA를 전체 341폼 UI 검증으로 확대 해석하지 않습니다.

## 최종 통합 확인 범위

런타임 확인 기준은 `8407dc4`입니다. 최종 문서·CI 연결은 계산 코드를 바꾸지 않습니다.

- Node 22에서 전체 566개 테스트·타입 검사·빌드·오프라인 산출물 검사를 통과했습니다.
- 홈·파티·대면·계산기·스피드라인·라이브러리·연구소·도감의 실제 역할별 동작을 확인했습니다.
- 실제 도감 목록의 341폼·730기술 ID를 끝까지 수집해 기대 집합과 프로그램으로 대조했습니다. 누락·초과·중복은 없었습니다. 모든 상세 페이지를 개별 순회한 뜻은 아닙니다.
- 390/320px에서 목록·일부 상세를 포함한 20개 경로를 측정했습니다. 페이지 가로 넘침은 없었으며, 기술표의 내부 가로 스크롤은 별개입니다.
- 공개 대면의 정식 아쿠아제트는 성격 편집 후 `91–108 → 100–118`, 독립 계산기의 집게덫은 `16–20 → 18–22`로 바뀌고 reload 후 유지됐습니다.
- 파티 편집·비교 초안·독립 Quick의 저장 대상 분리를 확인했고, QA에 쓴 세 origin의 원래 저장소를 원문 값까지 복원했습니다.
- 도구·특성의 전체 DOM 집합 순회, 모든 개체의 모든 언어, 실제 휴대폰 터치·글리프 가독성 검증은 수행 범위가 아닙니다.
