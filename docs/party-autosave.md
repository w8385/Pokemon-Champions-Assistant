# 파티 목록 편집·자동 저장

## 작업 흐름

- 목록의 파티를 클릭하거나 Enter로 선택하면 해당 파티를 바로 편집한다.
- 별도 파티 저장/불러오기/덮어쓰기 버튼은 사용하지 않는다.
- 종·성격·특성·도구·노력·기술 변경은 선택된 같은 ID의 파티 기록에 반영한다.
- 새 파티는 빈 여섯 슬롯 기록을 만들고 선택한다. 기존 파티는 남는다.
- 파티 이름 변경은 선택 기록에 반영한다. 삭제·현재 파티 비우기는 대상을 확인한다.

## 상태 경계

`party`, `confirmedMovesByKey`, `savedPartyPresets`, `activePartyPresetId`를 하나의 reducer 전이로 관리한다.
파티를 선택하는 전이에서 작업 파티·기술 맵·활성 ID가 함께 바뀐다.
A 선택 도중의 옛 값이 B 기록에 저장되는 후행 동기화 effect는 사용하지 않는다.

편집은 선택 기록의 ID·목록 개수를 유지한다. 다른 파티와 상대 기록은 변경하지 않는다.
샘플 삽입·OCR 확정·대면의 명시적 원본 반영은 현재 선택된 파티 기록에도 반영한다.
대면의 임시 조건과 미저장 비교 초안은 파티 원본에 자동 반영하지 않는다.

## 기존 데이터

- v1 저장 키와 백업을 유지하며 활성 ID는 선택 필드로 추가한다.
- 현재 작업 파티와 저장 기록이 같으면 해당 기록을 선택한다.
- 작업 중 내용이 저장 기록과 다르면 기존 기록을 덮지 않고 복구 파티 하나로 보존한다.
- working party가 없는 옛 데이터에서는 활성 저장 기록을 정본으로 복원한다. 기본 시작 파티를 복구본으로 잘못 추가하지 않는다.
- 재로드를 반복해도 복구 기록이 중복 생성되지 않아야 한다.
- 기술 네 칸의 빈 위치를 유지한다. 중복 종의 레거시 슬롯별 충돌 원본은 단순 선택·빌드 수정만으로 재작성하지 않는다.
- 기존 종별 공유 기술 모델은 유지한다. 기술을 직접 바꿀 때 선택 파티 안의 같은 종에만 반영하고 다른 파티의 기록은 보존한다.
- 빈 새 파티도 v1 전체 백업의 내보내기/가져오기를 지원한다.

## 저장 실패

- 실제 쓰기 성공 뒤에만 자동 저장됨을 표시한다.
- 쓰기 실패 시 화면 편집은 유지하며 저장 실패와 재시도를 표시한다.
- 읽기 실패 시 원본을 보호하고 기본 화면 값으로 즉시 덮어쓰지 않는다.
- 읽기 실패 원본을 대체하는 동작은 별도 명시 확인을 거친다.
- 저장소 객체를 얻는 접근 자체의 예외도 실패 안내와 재시도 범위에 포함한다. 실제 getter 예외 주입 후 편집 유지·원본 불변·접근 복구 후 재시도 성공을 확인했다.
- OCR은 시작 시 파티 ID와 선택 변경 횟수를 고정한다. 처리 중 다른 파티를 선택하거나 A→B→A로 돌아왔으면 반영하지 않고 재시도 안내를 표시한다. reducer도 다른 대상 ID의 쓰기를 거부한다. 이 경합은 지연 인식 결과를 주입해 검증했으며 실제 유료 OCR은 호출하지 않았다.

## 실제 검증과 제한

격리된 로컬 브라우저에서 파티 A→B→A, 빠른 선택, 필드·네 기술 변경, 강제 재로드, 새 빈 파티, 모달 소유권, 삭제 취소/승인을 실행했다.
기존 작업 파티의 복구·재로드 중복 방지, 빈 기술 위치·중복 종의 원본 보존, 직접 기술 수정의 선택 기록 한정 반영을 확인했다.
읽기·쓰기 예외를 주입해 원본 보호, 실패 안내, 재시도와 재로드를 확인했다.
빈 파티의 실제 v1 백업 내보내기와 파일 입력 가져오기도 확인했다.
working party가 없는 초기 입력 표시의 불일치를 수정하고, 실제 활성 기록과 종 검색 표시가 일치함을 재로드로 재확인했다.
파티 이름은 임시 입력 초안과 저장 기록을 분리했다. 이름을 모두 지운 뒤 새 이름을 입력해도 덧붙지 않으며, 중간 공백을 유지한다. 빈 초안은 저장하지 않고 포커스가 떠나면 마지막 저장 이름으로 복구됨을 실제 입력으로 확인했다.

브라우저 확인창 응답은 테스트에서 반환값을 주입했다. 실제 휴대전화 터치와 글꼴의 육안 가독성은 미검증이다.
원본 localStorage는 같은 출처 정적 SVG에서 전체 키·문자열을 복구하고 정확히 읽어 확인한 뒤 앱을 떠났다.

원본 기록·브라우저 픽스처는 공개 저장소 밖에 보관한다.
