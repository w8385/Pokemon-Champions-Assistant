# 파티 삭제 클릭 영역 및 능력치 순서 수정

## 재현

- 기준 커밋: `b08b0e1aafedb57fdfa8f905d857172be4788dfd`.
- 공개 Party 화면을 1280/390/320px에서 조사함.
- 기존 삭제 버튼은 카드 위 22×22px 절대 위치이며 종 검색창과 겹쳤음.
- 버튼 중앙과 안쪽 모서리의 `elementFromPoint` 결과가 버튼이 아닌 검색 input이었음.
- 카드 능력치 순서는 체력/특수공격/공격/특수방어/방어/스피드였고 모달 순서와 달랐음.

## 변경

- 실제 공용 `PokemonCardHeading`에 선택적인 actions 영역을 추가함.
- Party의 실제 삭제 버튼을 헤더의 별도 레이아웃 영역으로 이동함.
- 절대 위치를 제거하고 보이는 버튼과 클릭 영역을 모두 44×44px로 맞춤.
- 슬롯 번호를 접근 가능한 이름에 포함함. `clearPartySlot`의 데이터 처리 동작은 변경하지 않음.
- `src/statPresentation.ts`를 카드와 실제 공용 노력치 모달이 함께 사용하도록 함.
- 순서는 체력→공격→방어→특수공격→특수방어→스피드로 통일함.
- 기존 수치 계산, 키 기반 노력치 매핑, 번역 및 저장 형식은 유지함.

## 실행 검증

- 변경 전 회귀 테스트 실패와 변경 후 집중 테스트 3/3 통과를 확인함.
- 전체 286개 테스트, typecheck, build, diff check 통과함.
- 로컬 격리 fixture에서 3개 너비×6개 버튼의 90개 좌표가 실제 버튼을 가리킴을 확인함.
- 모든 조사 버튼이 44×44px이고 검색창과의 겹침 및 문서 가로 넘침이 0임.
- 1280/390/320px에서 버튼 중앙과 가장자리 6px 안쪽을 실제 좌표 클릭해 총 여섯 슬롯을 비움.
- 의도한 슬롯만 비워지고 다른 파티 슬롯, 상대 기록, 종별 기술 등록이 보존됨을 확인함.
- 빈 슬롯에서 버튼이 사라지고 재로드 후에도 해당 슬롯이 빈 상태임을 확인함.
- Party/Single/Quick/Builder 네 화면에서 실제 카드와 노력치 모달의 여섯 항목 순서가 같음을 확인함.
- 실제 사용자 파티는 삭제하지 않고 로컬 테스트 데이터로만 삭제 동작을 수행함.
