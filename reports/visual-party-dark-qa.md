## 다크 UI 감사 및 수정
현재 앱은 authored dark 단일 테마이며 라이트 전환기는 없음. OS 밝음/어둠 선호에 따라 별도 화면이 있다고 가정하지 않음.

실제 UI 대비 결함 네 건을 재현하고 수정:
1. 엔트리 버튼: 밝은 글자/흰 배경 → 다크 surface, 대비 1.17에서13.38로 개선.
2. 라이브러리 상세 링크: 브라우저 기본 파랑 → 지정 링크색, 대비1.88에서10.45로 개선.
3. 스피드라인 보조 정보: 미정의 muted 변수의 회색 fallback → 지정 muted 색, 대비3.94에서8.84로 개선.
4. 검색/샘플 이름 placeholder: 기본/개별 어두운 회색 → 공통 palette, 확인한 영역 대비8.51–9.37.

수치는 실제 computed style 및 배경 알파 합성으로 재측정. 이미지/그라데이션처럼 계산하지 못한 영역을 합격 처리하지 않음. 비활성·장식적 요소는 의미 있는 텍스트 결함과 구분.
