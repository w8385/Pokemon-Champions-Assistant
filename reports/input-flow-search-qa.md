## 구현

- Single 내 종 검색을 제거하고 등록 파티 슬롯의 종·폼만 표시함. 같은 카드의 빌드·노력치·기술 편집은 유지함.
- 이전 내 종 교체 비교 초안은 표시/원본 반영에 사용하지 않으며, 현재 종의 정상 빌드 초안은 유지함.
- 상대 종 선택은 실제 선택 슬롯에 기록한 뒤 다음 빈 슬롯으로 이동함. 끝에서 앞쪽 빈 슬롯을 찾으며, 여섯 칸이 차면 현재 슬롯에 머무름.
- 상대 입력 확정 후 실제 상대 검색창에 초점을 유지함. 입력 중·IME/229·취소된 추천 목록은 엔트리를 등록하거나 이동하지 않음.
- 상대 엔트리 초기화는 확인 후 여섯 기록과 상대 비교 초안을 지움. 취소 시 데이터 불변, 내 파티·내 빌드 초안·Quick·종별 기술 카탈로그는 보존함.
- 초기화 저장소 읽기/삭제 실패 시 경고하고 원본 초기화를 중단함. 부분 삭제한 초안은 복원 시도하고 복원 실패를 별도로 알림.
- 원본 상대가 이미 빈 상태라도 명시적 초기화는 양쪽 임시 상태·랭크·실수치·속도 가정·모달을 지우며 내 빌드는 보존함.
- Quick 공격측 종 확정 후 방어측 실제 검색 입력으로 초점을 이동함.
- `SearchCombobox`가 실제 입력·옵션·키보드·IME 상태를 소유함. 포켓몬 검색 어댑터와 실제 `RegisteredMoveSlot` 입력이 공유하며, Quick/Single·Party·Builder에 연결함.
- 샘플 대미지의 종 검색 복제를 실제 공용 검색으로 교체함. Dex/스피드라인 목록은 같은 기반 입력의 필터 모드로 유지하고 중복 드롭다운을 만들지 않음.
- 포켓몬과 기술은 공통 순수 매칭을 사용함. 정식명/명시 별칭, 접두·부분 문자열, 한글 초성·줄임말, 제공된 EN/JA 이름과 전각·구두점 정규화를 지원함.
- 정확한 초성 일치를 더 긴 초성 접두 일치보다 먼저 표시함. 예: `ㅎㅇㅂ`의 첫 후보는 화염볼이며 화염방사도 아래에 남음.
- 선택기는 제공된 적격 기술풀 안에서만 검색함. 모호한 줄임말은 후보를 유지하며 임의로 유일한 기술로 확정하지 않음.
- `HP 100%` 문구를 적용함. 1:1 조건 UI에서 프렌드가드를 제거하고 저장된 true도 피해 보정에 적용하지 않음. 실제 특성 목록과 더블 데이터/엔진은 유지함.
