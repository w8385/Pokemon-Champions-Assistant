# 공통 디자인 계약 구현·검증

## 범위

원칙: 입력과 결과를 가까이 두고, 같은 조작은 같은 실제 UI로.
기준 커밋: `fc276828a7fe4841399434f06b84210ef7d59ba7`.
규칙과 토큰은 루트 `DESIGN.md`, `tokens.json`에 둠.
모바일 좌우 2열은 사용자의 질문에 제안한 상태이며 이번 변경에 적용하지 않음.

## 실제 구현

- Single/Quick의 실제 편집 카드 안에 공용 빌드 필드와 여섯 능력치를 기술보다 먼저 배치함.
- 유효 Speed와 선택 기술 피해를 하나의 영역에 연속 배치함.
- Single 상대 슬롯 바로 아래에 공용 `PokemonSearchField`로 상대 엔트리 입력을 노출함.
- 기본 카드의 저장됨/엔트리 저장/변경 취소를 제거함.
- 비교 빌드 초안은 버전·슬롯·원본 시드를 검증하는 별도 저장소로 자동 보관함.
- 원본 파티/상대 기록은 목적지가 명확한 선택적 반영 버튼으로 dirty 빌드 필드만 갱신함.
- Party/Builder 종 검색과 Builder 노력치 모달을 실제 공용 컴포넌트로 통합함.
- 공통 컨트롤에 기존 다크 팔레트 기반 토큰과 포커스/호버/비활성 상태를 적용함.

## 발견 후 수정한 차단 오류

- 같은 슬롯의 상대 종 변경 시 내 화상이 남던 현상을 수정함. 두 측의 임시 가정은 대면 종·폼·슬롯 변경 시 초기화하고 빌드 초안은 보존함.
- 초안 쓰기/삭제에서 저장소 오류가 나면 계산을 중단하던 현상을 수정함. 실패 상태를 표시하고 현재 화면 계산을 유지함.
- Builder에서 메가폼을 일반 종으로 변경할 때 이전 메가스톤이 남던 현상을 수정함.
- Dex 상세 chip의 분류 간 이동이 이력에 남지 않던 현상을 수정함. 입력 중 검색어는 이력을 늘리지 않고 상세 이동은 Back/Forward로 복원함.

## 메뉴별 실장 검증

- Home: 상단 8개 native 직접 링크, 카드 7개 목적지, 키보드 Enter, 활성 메뉴를 확인함.
- Party: 공용 검색의 첫 가시 결과 Enter 선택, 모달 Escape, 6개 카드 뒤 방어/공격 각각 18×9 표, 표 내부 스크롤, 저장 슬롯 재로드 보존을 확인함.
- Single: 명시적 상대 입력, 슬롯/카드/Speed 종 일치, 스탯 클릭 모달, 스탯→기술 순서, 결과 인접, 실시간 조건 반영을 확인함. 수치 fixture Speed 139/138, 무릎차기 84–100, 리베로 해제 56–67을 확인함. 초안 재로드/원본 분리와 상대 기록 반영 시 내 초안 보존을 확인함. 수정 후 상대 종 변경에서 내 화상과 +2 Speed 랭크가 false/0으로 초기화됨을 재검사함.
- Quick: 독립 종 검색, 한 기술 계산, 공수 교체/재로드, 원본 파티 불변을 확인함. 추가로 양쪽 네 기술을 각각 실제 입력·Enter로 등록하고 여덟 값을 읽어 확인함.
- SpeedLine: 기준 종 Enter 선택, 실수치/유효 Speed, 추월 투자 상세, 필터/상세 재로드를 확인함.
- Library: 목록/읽기 전용 상세/출처/확인된 능력치, 개별 빌더 가져오기를 확인함. 확인된 여섯 샘플을 저장 파티로 가져온 뒤 6개 멤버를 읽고 활성 파티가 바뀌지 않음을 확인함. 미확인 전체 파티의 가져오기 미노출도 확인함.
- Builder: 공용 종 검색, 실제 노력치 모달 Escape/화면 이탈/Back 재등장 방지, 실제 포인터 opener 초점 복귀, 샘플 저장/재로드를 확인함. 수정 후 메가갸라도스→에이스번에서 갸라도스나이트→미선택을 확인함.
- Dex: 검색 확정, Pokémon→Move→Pokémon 원자적 이동, 수정 후 실제 Back/Forward 복원, 조합 중 Enter/keyCode229 미확정을 확인함.

## 크기·검사·한계

- 최초 감사와 통합 검증 뒤, 수정 후 다시 1280/390px에서 8개 메뉴, 320px에서 Single/Quick를 측정해 총 18개 최종 배치 기록을 보관함.
- 최종 기록의 문서 가로 넘침은 모두 0이며, 두 결과는 8px 간격이고 능력치가 기술보다 앞임.
- 320px 양측 네 기술의 2×2 배치와 Speed track 물리 너비 일치는 통합 QA에서 확인함.
- 실제 QuotaExceededError 주입 시 자동 보관 실패 안내와 화면/계산 유지, HP 노력 0→1에 따른 155→156을 확인함.
- DESIGN lint는 오류 0/경고 0임. 토큰 검사와 표본 검증은 전체 접근성 인증이 아님.
- 캡처 환경에 CJK 글꼴이 없어 한글 글리프의 시각 품질은 판정하지 않음. 전체 세션 콘솔 스트림 검사는 하지 않음.
- 빌드의 기존 대형 청크 경고는 남아 있음. 공개 배포 검증은 별도 릴리스 증거로 기록함.
- QA 브라우저 원래 저장값은 초기화 완료 후 다시 써서 값 단위 동일성을 확인함.
