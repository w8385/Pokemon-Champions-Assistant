# 메뉴·라이브러리·도감 UI 갱신 QA

## 범위
- 상단 메뉴 여덟 개를 홈 / 내 파티 / 대면 / 계산기 / 스피드라인 / 샘플 라이브러리 / 샘플 연구소 / 도감 직접 링크로 정리함.
- 샘플 내부 네 탭을 제거하고 기존 빌드·노력 모달·기술 네 칸·스피드·대미지·저장·적용 UI를 연구소 한 화면에 보존함.
- 라이브러리 전체 지역 기본값, 별도 개인 링크 지역, 목록 문맥 URL 및 상세 복귀를 구현함.
- 도감 다열 목록과 URL 기반 독립 상세를 연결하고 기존 네 분류 상세·툴팁·빌더 이동·파티 교체 확인을 보존함.
- 도감 기술 목록은 대전용 기존 seed와 분리된 고정 게임 데이터 스냅샷을 사용함. 기존 계산 엔진·대전 기술풀·저장 레코드를 바꾸지 않음.

## 기술 데이터의 정확한 범위
- 출처는 Project Pokémon `champout` 커밋 `50e7233b78c3b81df29563f9695386c28e77fc95`, 2026-09-09 스냅샷임.
- 종·폼별 `waza_learn.waza`와 기술 테이블의 `available == "1"`을 교차함. 이름만 사용 가능 목록처럼 보이는 parser 합집합은 사용하지 않음.
- 유효 roster 341개 키 중 339개를 명시적인 원본 종·폼 ID와 대응함. 능력치·원본 폼 이름·원본 파일 해시를 재생성 시 재검증함.
- `mega-meowstic`의 성별과 `tauros-paldean`의 품종은 앱 키만으로 확정할 수 없어 목록을 합치지 않고 미확정 상태로 표시함.
- 대응된 학습 목록에 나타나는 활성 기술 ID는 510개임. 세 표기 차이는 동일 기술 ID로 기존 앱 이름과 연결하며 원문 한국어명을 별도로 보존함. ID 747은 메타데이터가 없어 원문 이름과 미확인 수치를 유지함.
- 2026-10-18 실서버와 같은 버전인지, 현 레귤레이션 적법성 전체가 같은지는 검증하지 않음. 화면에 스냅샷 날짜·출처와 현 버전 일치 미검증 경고를 표시함.
- 부모가 고정 upstream을 다시 내려받는 생성기를 실행해 원본 해시 검증과 재생성 결과 동일성을 확인함. 최종 기술풀 SHA-256은 `32a45e3e18490b0d5f7048d5c4959240505340ad8756301384e40c5754147817`이며 동기식 기술 식별 인덱스는 `821c977af77863f53abffd95668e4173d67b42de76d8e1c79c89903d54ec9c3c`임.

## 자동 검사

- TypeScript 검사, Vite 빌드, `git diff --check` 통과함.

- 기존 500kB 초과 chunk 경고는 남아 있음. 도감 스냅샷은 별도 lazy chunk로 측정됨.

## 실제 브라우저 검증

### 메뉴와 연구소
- 1280px와 390px에서 여덟 직접 메뉴의 목적지·제목·단일 활성 링크·본문 존재·가로 넘침 없음 확인함.
- 헤더 스피드라인 링크의 실제 Enter 이동 확인함.
- 연구소의 기존 빌드/스피드/대미지/저장 섹션과 잔여 서브메뉴 제거 확인함.
- 메가이어롭 스피드 노력 0→1에서 빌드·스피드 수치 170→171 반영 확인함.
- 성격 및 공격 노력 변경 후 인파이트 대 한카리아스 실대미지 102–120→121–144 반영 확인함.
- 실제 네 콤보박스, 노력 모달 Escape·포커스 복귀·화면 이탈 시 닫힘, 샘플 저장 후 재접속 확인함.
- 파티 적용 취소 시 불변, 확인 시 선택한 2번 슬롯만 변경됨을 확인함. 기술 카탈로그의 종 공유 범위도 보존됨.
- 레거시 builder/speed/damage는 연구소 기능을 보존하고 rankers는 라이브러리로 정규화됨.

### 라이브러리
- 전체 13개 출처가 KR 3개와 JP 10개의 중복 없는 합집합임을 canonical identity로 비교함.
- JA/M-6/singles 목록→상세→브라우저 Back에서 같은 필터·검색·목록·scrollY 300 복원 확인함.
- Forward/상세 새로고침/화면 목록 링크에서 지역·검색·형식 복원 확인함. 새로고침 후 화면 목록 링크의 scrollY는 0으로 관찰됨.
- 개별 샘플 상세 새로고침 후 개별 목록으로 돌아옴을 확인함.
- 지역 전체에서 신규 개인 링크의 명시적 JA 지역이 저장·재접속 후 유지됨. `all`을 저장 언어로 쓰지 않음.
- 잘못된 출처는 다른 파티를 보여주지 않고 미발견과 안전한 목록 링크를 표시함.

### 도감
- 1280px 실제 네 열, 390px 두 열과 가로 넘침 없음 확인함. 첫 진입 목록은 상세를 자동으로 열지 않음.
- 네 분류의 카드 클릭→독립 상세→브라우저 Back 확인함. 도구 첫 카드의 별칭 인덱스 오류를 재현·수정하고 재접속까지 재검증함.
- 직접 상세/Forward/새로고침과 잘못된 Pokémon key 복구 확인함.
- 비어 있지 않은 로토무 검색→워시로토무→부유→메가마폭시→Back 연속 이동에서 분류·선택·검색 문맥이 유지됨.
- 도감 카드의 실제 Enter, 도감·라이브러리의 실제 Ctrl+클릭에서 새 탭이 열리고 현재 탭이 바뀌지 않음을 확인함. 생성한 QA 탭은 닫음.
- 로토무 기본 42개, 다섯 가전폼 각 43개, 메가루카리오Z 83개, 히스이 대검귀 68개, 메가후딘 60개 및 ID 747 포함 종의 전체 DOM 기술명을 생성 데이터와 비교해 일치 확인함.
- 두 모호 폼은 0개로 확정하지 않고 명시적 미확정 문구를 표시함.
- 워시로토무 검색에서 전체 43/표시 1, 상태기 필터에서 전체 43/표시 21을 확인함. 좁은 화면은 표 영역만 가로 스크롤하며 문서 자체는 넘치지 않음.
- 네트워크를 막아 로드 실패·무한 자동 재시도 없음 확인함. 최초 구현의 실패한 module import 재사용 문제를 재현한 뒤, 명시적 재시도가 동일 URL 새로고침으로 복구하도록 수정함. 차단 해제 후 실제 43개 목록 복구를 재검증함.

## 증거와 제한
- 첫 독립 검토에서 기술 링크의 새 탭 분류, ID 747 상세, 기존 메타에 따른 잘못된 타입 표시가 발견됨. 별도 수정자가 세 항목을 회귀 테스트와 함께 수정함. 부모가 새 탭 URL·일반 클릭·새 직접 주소·성장 풀 타입·집게덫 강철 타입과 강철 필터를 실제 화면에서 재검증함.
- 재검토에서 공통 기술 검색 옵션의 레거시 타입 우선과 ID 747 검색 누락이 발견됨. 공통 옵션을 원본 기술 식별자·타입 우선의 합집합으로 수정하고 기존 레거시 검색은 보존함. 부모가 성장·집게덫·볼가득넣기 검색 카드와 상세를 실제로 재검증했으며, 미수록 분류는 없음이 아닌 미확인으로 표시됨.
- 기술 상세의 역방향 습득 목록도 같은 339개 폼 스냅샷에서 비동기 역산하도록 수정함. 510개 기술 전부의 역방향 일치를 회귀 검사하고, 부모가 ID 747의 꿀꺽몬·바오키·앗차키·야나키 네 항목, 포켓몬 상세 이동·Back, 로드 실패·새로고침 재시도 복구를 실제로 확인함.
- 타입은 고정 원본 ID 0–17에서 검증해 사용하고, 다른 PP·위력·명중·설명은 기존 도감 메타임을 구분함. ID 747의 타입은 노말로 확인하되 나머지 미수록 수치와 설명은 미확인으로 유지함.
- 로컬 원자료: `~/.hermes/artifacts/pokemon-champions/2026-10-18/navigation-library-refresh/`의 `parent-browser/`, `qa-lab/`, `parent-final/`, `learnset-primary/`에 저장함.
- 각 QA는 원래 저장값 전체를 동일 출처의 정적 SVG에서 복구하고 실제 문자열을 비교한 뒤 앱에서 이탈함. 자식 세션의 복구는 해당 세션의 직접 readback 증거 기준이며, 같은 이름으로 시작한 부모 브라우저가 동일 인스턴스라고 가정하지 않음.
- 마우스·CDP 키보드 검증임. 실제 휴대폰 터치와 한글 글리프의 육안 품질, 전체 접근성 인증은 주장하지 않음.
- 일부 기술 메타데이터와 도구 설명은 미수록 상태임. 없는 설명이나 수치를 만들어 채우지 않음.
- 최종 독립 리뷰·commit·push·Pages·공개 재검증은 별도 단계임. 이 보고서는 배포 성공을 주장하지 않음.
