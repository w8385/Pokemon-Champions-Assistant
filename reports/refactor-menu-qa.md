## 기대 동작과 확인 범위

- 홈/상단 메뉴: 해당 화면으로 진입. 홈 샘플 빌더는 이전 자료 탭과 무관하게 빌더 진입. 확인됨.
- 싱글 파티: 자동완성, 기술 등록, EV 변경, 저장/이름변경/적용/새로고침. 브라우저 확인됨.
- 상대 엔트리: 빠른 입력/무결과/초기화, 선출 추정 각 3마리 상한. 누락 버튼 수정 후 확인됨.
- 싱글 스피드/대미지: 빈 상대 안내, 스피드 변경 반영, 공격 랭크 변경에 따른 대미지 재계산. 확인됨. 모든 조건의 수치 동등성은 검사하지 않음.
- 더블: 플래너 순풍/트릭룸 순서, 방어 차단, 노력치 모달. 확인됨. 잘못된 speed 경로는 power로 정규화.
- 샘플 빌더: 공유 6개 능력치 타일, 조정 모달, 종 변경, 총 66 포인트 제한, 파티 다른 슬롯 적용. 확인됨.
- 샘플 계산기: 대상 교체/제거, 스테이지/내구 변경에 따른 결과 변화. 확인됨.
- 크리에이터 자료: 파티/개별 구분, 두 멤버의 하나의 출처 그룹, 원본 실수치/성격/EV/기술, 필터 및 개인 링크 중복/삭제. 확인됨. 자료 화면 저장/파티 적용 없음.
- 랭커: 근거 없는 순위는 빈 목록; 자료 입력 폼/빌더 저장 버튼 없음. 확인됨.
- 실능 스피드라인: 내림차순, 검색, 성격/메가 필터, EV 상한. 확인됨.
- 도감: 포켓몬/기술/특성/도구 검색 및 상세, 무결과, URL 복원, 모바일 배치. 주요 동작 확인됨. IME 전체 조합은 미검증.
- 백업: 유효 JSON 내보내기/초기화/복원. 지원하지 않는 버전 및 malformed 내부 값 거절 시 기존 상태 유지. 브라우저와 자동 회귀검사 확인됨.

## 수정한 불일치

1. 자료/랭커 화면에 빌더 저장·적용 노출: 차단.
2. 홈 샘플 빌더의 마지막 자료 탭 복원: 명시적 빌더 진입.
3. 더블 speed 딥링크 빈 본문: 플래너 power 정규화, persisted speed도 정규화.
4. 선출 상한 로직에 UI 연결 누락: 양측 버튼 연결, 빈 슬롯 선택 금지.
5. 백업 지원 버전/내부 스키마 검사 누락: 검증 강화.
6. 백업 복원 중 일부만 반영 가능: 전체 준비 이후 setter 호출.
7. 4마리 선출 및 빈 저장 항목 백업 허용: 거절.
