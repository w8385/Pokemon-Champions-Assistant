- 실제 기존 도감 카드 그리드에서 24개씩 추가 표시함. 데이터가 아니라 렌더링 범위만 나눔.
- 아래 감지 영역에서 자동 추가하며, IntersectionObserver가 없을 때는 키보드로도 사용할 수 있는 더보기 버튼을 제공함.
- 검색·분류가 바뀌면 초기 표시 범위로 복귀함. 상세를 열었다가 목록으로 돌아올 때 표시 수와 스크롤을 복원함.
- 다른 화면의 콤보박스 제한, 기존 게임 데이터·계산 엔진·사용자 기록은 변경하지 않음.

## 실측
- 공개 기존 버전은 스크롤 후에도 포켓몬12, 기술48, 특성48, 도구48개에서 멈추는 것을 재현함.
- 로컬 1280px에서 자동 스크롤만으로 포켓몬341/기술732/특성215/도구82개 끝까지 도달함. 각 canonical ID 집합의 크기와 렌더 수·전체 수가 일치하고 중복이 없음을 확인함.
- 메가 검색 결과82개도 끝까지 도달함. 뒷부분 상세→브라우저 Back과 화면 목록 링크에서82개·검색어·scrollY2581을 복원함.
- 포켓몬 상세→특성 상세→다른 포켓몬 상세를 거친 복귀에서는 초기 구현이 스크롤을0으로 잃는 오류가 있었음. 검색·렌더 준비 후 복원하고 경로 변경 시 예약을 취소하도록 수정함. 같은 연속 이동을 재검증해82개와 scrollY2854가 정확히 복원됨.
- 검색어를 로토무로 바꾸면6개만 표시해 이전 범위가 섞이지 않음.
- 390px에서도 자동 스크롤로 포켓몬341개까지 도달하며2열·문서 가로 넘침 없음 확인함.
- 실제 window.IntersectionObserver를 비활성화한 뒤 분류를 바꿔 새 감지 컴포넌트를 마운트함. 자동 추가 없이24개 유지, 실제 Enter 더보기로48개, 수동 추가로 도구82개 끝까지 도달함.
- 초기 자동 스크롤 QA는 배경 탭 상태로 감지되지 않았음. 전경 활성화 후 재검증했으며 앱 결함으로 취급하지 않음. 초기 새 문서 주입 방식의 Observer 비활성화도 적용되지 않았으므로, 해당 결과를 대체 경로 검증으로 사용하지 않고 실제 비활성화 여부를 확인한 별도 검증을 사용함.
- 각 배치 후 원래 localStorage 전체를 동일 출처 정적 SVG에서 정확히 복구하고 앱에서 이탈함.
